# Spatial Spline 规划器—机器人契约（v1）

此文档描述 **现有机器人 SplineTrajectoryLoader** 可执行的数据，并不代表机器人代码已升级。

## 两种 JSON 格式

- 规划器本地归档 /「导出 JSON」：`[{"robotName":"default","routes":[{"name":"...","points":[...]}]}]`，可保存多个路径。
- 机器人网络 V2 单路径内容：裸 JSON 数组 `[{"x":0,"y":0,"dx":30,"dy":0}, ...]`，不能上传归档包装对象。
- 规划器上传、自动同步会统一转换为机器人格式。拉取时恢复为 `ControlNode`。

## 字段（参数属于到达该节点的路段）

| 字段 | 单位 | 机器人语义 |
|---|---|---|
| `x`, `y` | 英寸 | 路段终点；必填 |
| `dx`, `dy` | 英寸 / 无量纲 u | Hermite 几何切线，**不是**真实运动速度 |
| `heading` | 度 | 目标朝向；采用最短转角，使用零端点导数的 Hermite 曲线 |
| `dHeading` | 度 / u | 兼容保留，但现有空间跟踪器不读取；预览同样忽略 |
| `maxPower` | 0–1 | 巡航正向功率，默认 1 |
| `maxSpeed` | 英寸/秒 | 可选限速；留空表示不限速 |
| `endSpeed` | 英寸/秒 | 可选到点目标速度；留空时**不是**停车点，0 时要求低速停靠 |
| `brakeZoneIn` | 英寸 | 指定 `endSpeed` 时必须为正数 |
| `brakeForwardPower` | 0–1 | 可选制动区正向功率上限；留空使用机器人默认值 |
| `duration` | 秒 | **仅控制规划器预览**，机器人不按时间跟踪 |
| `delayAfterArrive` | 秒 | 规划器上传时改写成紧随对应节点的 `{"wait":秒数}`；机器人实际执行等待 |
| `marker`, `command`, `commandParams` | 文本 | 原样保留在节点；**当前机器人 RouteAutoOpMode 丢弃这些事件，不执行动作** |

上述可选运动字段未设置时，规划器不会将其编码为 JSON `null`。机器人解析器也不要求在每个节点设置制动参数。

## 预览与真实行为的边界

- X/Y 几何曲线与机器人采用同一三次 Hermite 系数。规划器以 `duration` 显示轨迹时间轴；机器人用当前位置在曲线上的空间投影推进，速度与预计到达时间可能不同。
- 停车点应设置 `endSpeed=0` 和经过标定的 `brakeZoneIn>0`；编辑器的 12 英寸快捷预设只是初始值，**不是经过实机验证的参数**。
- 最后一个节点如果没有设置零速停车，只在通过终点条件后停止电机，不保证精确停止位置。规划器会警告，但仍允许上传兼容的旧路线。
- 设置到点等待会在机器人端生成独立 WAIT 步骤；最好搭配零速停车点。第一个节点的到点等待也包含在规划器的时间轴预览内。
- 独立 WAIT 目前只能无损映射到紧邻的前一个控制点。前置 WAIT 或带独立事件的 WAIT 不会被悄悄丢弃，而会拒绝导入为编辑器路线。
- 节点命令的执行需要机器人端另行升级；**本次只修改规划器，不会让机器人实际触发命令**。

## 校验与测试

规划器在节点编辑器中检查数据，在路径列表提示错误/警告，在网络 HTTP PUT 入口统一校验（覆盖手动上传与自动同步）。非法坐标、功率、限速、制动参数或格式会在网络请求发出前被拒绝。`route/SplineRouteContractTest`、`io/network/RobotApiClientContractTest` 及同步测试覆盖编码、反向导入和异常参数。
